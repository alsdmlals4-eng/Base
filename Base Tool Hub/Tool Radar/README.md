# Tool Radar

**현재 상태:** `DESIGN_ONLY_ABSORPTION_TARGET`

외부 개발 도구를 조사·비교해 Base에 채택할지 판단하는 기능은 별도 권한 앱으로 유지하지 않고 **Base Tool Hub의 discovery/benchmark 모듈로 흡수**하는 방향입니다.

목표:

- 공식 문서·현업 사례·유지보수 상태·라이선스·비용·Godot 적합성 비교
- `채택 / 변형 / 제외` 결론과 이유 기록
- 이미 Base에 있는 기능과 중복이면 새 도구를 만들지 않음

현재 정적 HTML Tool Radar 작업물은 제품 실행 정본이 아니며, 실제 Tool Hub 카탈로그에 연결되기 전에는 구현 완료로 보지 않습니다.
