# Goal and Authority

## Goal

하나의 공용 Loop Kernel과 프로젝트별 선언형 Execution Capsule을 사용한다. 사용자가 GPT와 확정·검수한 기획과 아트 디자인을 잠근 뒤 Agent는 기술적 HOW만 자동 실행한다.

```text
Human-led WHAT / WHY
Agent-led HOW
No omission
No unauthorized addition
No planning drift
No visual drift
No cross-project context leak
```

## Authority

```text
최신 사용자 승인
→ 프로젝트 AGENTS·보안·엔진·데이터 규칙
→ 승인 Decision·GDD·Planning Lock
→ Visual Lock·승인 시각 Registry
→ Asset Manifest·tracked asset
→ 실제 코드·데이터·Scene·테스트
→ 채택한 Base 계약
→ 외부 레퍼런스·WIP·AI 추론
```

Planning Lock은 규칙·경험·콘텐츠 의미를, Visual Lock은 비율·색·형태·카메라·UI 위계와 금지 drift를 소유한다. Figma는 Visual Lock provider일 뿐 Planning Lock을 덮지 않는다. 실제 이미지 bytes는 Asset Vault 또는 tracked asset, 실제 구현 결과는 Runtime Capture가 증명한다.

Kernel은 상태·권한·Lease·Coverage·Drift·Evidence·Integration을 판정한다. Agent는 조사·구현·테스트·비판을 수행하지만 자신의 권한·완료·병합 상태를 최종 승인하지 않는다.
