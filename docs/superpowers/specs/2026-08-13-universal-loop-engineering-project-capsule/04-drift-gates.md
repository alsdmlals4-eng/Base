# Drift Gates

기획 차이는 변화 없음, 기술 구현 차이, 사용자 결정이 필요한 기획 충돌로 구분한다. 내부 구조만 바뀌고 플레이 경험과 의미가 유지되면 기술 차이로 처리할 수 있다. 기능 의미, 주요 UX, 경제, 콘텐츠, 저장 의미가 바뀌면 자동 실행을 멈춘다.

시각 차이는 시각 영향 없음, 승인 기준 일치, 의도된 차이, 구현 누락, 시각 정본 충돌, 검증 불가로 구분한다. 실제 Runtime Capture가 없으면 승인 시안과 일치했다고 판정하지 않는다.

자산은 승인 자산 재사용, 승인 범위 변형, 미승인 자산, 출처 누락, 다른 프로젝트 자산 혼입으로 구분한다. 해결되지 않은 중요 차이가 남으면 병합 Gate를 통과하지 못한다.
