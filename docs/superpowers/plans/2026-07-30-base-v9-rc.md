# Base v9.0.0-rc.1 구현 계획

> **For agentic workers:** Base v9 RC는 `PLAN → BUILD → REVIEW` 순서를 따르며, 각 변경은 테스트와 실제 생성물로 검증한다.

**Goal:** Base 공용 운영체계를 Plugin·동적 Skill Registry·고정 가능한 프로젝트 snapshot으로 재구성하고, 프로젝트 적용은 보류한 공통 작업지시문을 제공한다.

**Architecture:** `skills/`와 `SKILL_REGISTRY.json`이 활성 Skill의 단일 기계 원본이다. 생성기는 Registry와 frontmatter를 검증해 사람용 표와 프로젝트별 snapshot을 만들고, 문서는 생성된 수치를 복제하지 않는다. 정책·schema·template은 Base 공용 계약만 보유하며 프로젝트 고유 정보는 보류 작업지시문으로 분리한다.

**Tech Stack:** Python 표준 라이브러리와 jsonschema, JSON Schema Draft 2020-12, GitHub Actions, Markdown, Codex Plugin manifest.

## Global Constraints

- Base의 활성 Skill 수는 고정값이 아니라 Registry에서 계산되는 관찰값이다.
- 기존 공용 Skill 본문은 프로젝트 저장소에 복제하지 않는다.
- 실제 Google Sheets, 5개 프로젝트 저장소, Ruleset·branch protection은 변경하지 않는다.
- 모든 새 GDScript 파일이 생길 경우 첫 줄에는 한국어 역할 주석을 둔다. 이번 작업은 GDScript를 만들지 않는다.
- v9.0.0 최종 릴리스는 프로젝트 적용 Wave 2 증거 전에는 발행하지 않는다.
