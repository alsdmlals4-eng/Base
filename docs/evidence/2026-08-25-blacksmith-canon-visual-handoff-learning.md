## 3. Reusable rule reinforced

When a successor state becomes current:

```text
1. identify every current-state consumer and regression assertion;
2. classify each assertion as CURRENT_MUTABLE or HISTORICAL_DISCOVERY;
3. advance CURRENT_MUTABLE assertions to the successor state;
4. preserve HISTORICAL_DISCOVERY values as provenance;
5. never satisfy a current regression by re-introducing a predecessor token solely for compatibility;
6. rerun the consuming workflow, not merely a newly-created standalone test file.
```

A historical document may still contain the old value. That is not drift if its status is explicit and current routing wins. A current regression test requiring the old value **is** drift.
