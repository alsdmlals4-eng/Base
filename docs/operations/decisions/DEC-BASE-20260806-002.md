
## Problem

The exact protected-baseline validator correctly blocks unapproved changes, but the installed all-PR workflow also blocks an approved gameplay or runtime change forever. Refreshing the adapter baseline cannot solve the same pull request because validation still compares the protected product paths against that immutable base. This is a contract deadlock, not a product defect.

## Decision

Keep the existing validator unchanged and add one narrow outer gate.

An exact protected-path error may be reconciled only when all conditions hold:

1. the normal Base validator produced exactly one `Protected-path changes detected` error;
2. every other Base validator error remains unchanged and fatal;
3. a committed `PROJECT_PROTECTED_CHANGE_APPROVAL` document names the exact trusted baseline commit;
4. `approved_paths` exactly equals the detected protected paths, with no wildcard, extra, or missing path;
5. at least one approved project Decision ID and an approval source are recorded;
6. GitHub pull-request metadata supplies an external approval marker;
7. the project workflow is pinned to a reviewed merged Base commit containing this gate.

A manifest without external approval, a label without a manifest, a stale baseline, or a path mismatch fails closed.

## Rejected alternatives

- Removing or weakening `protected_paths`: rejected because it loses the safety boundary.
- Ignoring the adapter workflow for product pull requests: rejected because it leaves protected changes unaudited.
- Treating the manifest alone as approval: rejected as same-branch self-attestation.
- Rewriting the existing validator core: rejected because a thin reconciler preserves the already verified failure surface.

## Validation

- focused unit tests for exact approval, missing external approval, stale baseline, extra/missing paths, Decision identity, and non-protected error preservation;
- existing Base v9 contract suite;
- adversarial review before merge;
- project pilot on Ten Paces PR #92 after the Base merge and exact validator pin update.
