## RED/GREEN findings

### RED 1 — Pilot parse failure

```text
Cannot infer the type of "passed" variable
```

Fix: declare `var passed: bool` in the Pilot wrapper.

### RED 2 — numeric operation IDs rejected

Both mutations returned `LEDGER_START_FAILED` because the ledger's confined name check accepted identifier characters and `-` but rejected digits in IDs such as `op-rename-dirty-001`.

Fix: allow `character.is_valid_int()` while continuing to reject `/`, `\\`, `..`, and other unsafe characters.

### GREEN

After both fixes, inspect, dirty rename, undo, saved rename, terminal ledgers, saved-file byte hash, and listener-disabled checks all passed in the same Godot 4.7.1 Editor run.
