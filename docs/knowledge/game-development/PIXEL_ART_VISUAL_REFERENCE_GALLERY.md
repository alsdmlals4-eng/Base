## 사용 원칙

**외부 예시는 스타일 정의가 아니라 관찰 자료**다. 한 장의 이미지가 Preset 전체를 대표하거나 특정 조합을 강제하지 않는다. 각 카드의 `observe`만 추출해 프로젝트 고유 Art Direction과 다시 조합한다.

이 Gallery의 이미지는 외부 원출처에 있는 예시를 원격 표시한다. 저장소 제품 자산으로 복사·승격하지 않으며 **PROJECT_ASSET_APPROVED를 부여하지 않는다**. 원격 파일이 사라지거나 라이선스·원출처 상태가 바뀌면 해당 카드를 `STALE_RECHECK_REQUIRED`로 처리한다.

- `reference_status: REFERENCE_ONLY`는 제품 사용 허가 판정이 아니다.
- 표시된 license는 확인일의 원출처 표기다. 실제 제품 채택 시 프로젝트 자산 권리 Gate에서 재확인한다.
- 같은 이미지가 둘 이상의 Preset에 등장할 수 있다. 이 경우 이미지 자체가 아니라 서로 다른 관찰 축을 보는 것이다.
- 외부 작품의 캐릭터·구도·고유 디자인을 복제하지 않는다.

## Reference 선택 시 체크

1. 예시에서 보고 싶은 축을 `observe` 한 문장으로 말할 수 있는가.
2. 원출처와 현재 license가 확인되는가.
3. 프로젝트의 기존 승인 Visual Reference와 충돌하지 않는가.
4. 외부 고유 디자인을 떼어 내도 적용 가능한 일반 원리가 남는가.
5. 실제 프로젝트 후보는 최소 3개 실질 대안과 함께 비교되는가.
6. 최종 선택 직전에 더 나은 대안을 한 번 더 탐색하고 장기 제작비를 재검토했는가.

원격 예시는 링크 부패가 가능하므로 장기 보존이 필요한 프로젝트 승인 자료는 외부 이미지를 무단 복사하는 대신, 프로젝트가 권리·출처를 재검증한 자체 Visual Bible Reference 또는 독립 제작물로 교체한다.
