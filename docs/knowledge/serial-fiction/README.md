# Serial Fiction Knowledge Hub

이 디렉터리는 웹소설·연재소설의 공용 집필·퇴고 판단을 관리한다. 작품별 세계관·인물·사건·POV 수·장르 비율·플랫폼 production target은 각 프로젝트가 소유한다.

## 시작 경로

```text
소설·웹소설·연재소설 요청
→ skills/developing-and-revising-serial-fiction/SKILL.md
→ 현재 작업에 필요한 Guide만 선택
→ 프로젝트 정본·실제 원고
→ 필요 시 running-adversarial-review-and-refinement
```

## Guides

- `SERIAL_FICTION_WRITING_AND_REVISION_GUIDE.md`
  - Reader Promise, 장면 극화, POV·voice, 대사·내면, 느림과 정체, 퇴고 순서, originality 경계
- `SERIAL_EPISODE_PACING_AND_PAYOFF_GUIDE.md`
  - Episode Value, 회차 경계, Local Payoff, Open Loop, Pattern Variation, Consequence Memory, Setup–Payoff Debt, 플랫폼 분량 검증
- `READER_FEEDBACK_AND_BENCHMARK_EVIDENCE_GUIDE.md`
  - 인기작·현업 자료·댓글·리뷰의 Evidence 분리, 반례, 표본 한계, transfer decision

## Authority boundary

이 Hub는 다음을 정본으로 만들지 않는다.

- 특정 작품의 줄거리·캐릭터·설정
- 특정 현역 작가의 문체·대표 표현
- 특정 플랫폼의 영구 고정 글자 수
- 개별 댓글·리뷰의 해결책
- 프로젝트의 실제 독자 반응·판매 성과

플랫폼 정책·과금·분량 조건은 실제 적용 시 현재 공식 원본을 다시 확인한다. 오래된 표본만 있으면 `PLATFORM_REVERIFY_REQUIRED`다.
