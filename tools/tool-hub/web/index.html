프로젝트 연결

프로젝트 이름을 선택하면 PC의 표준 Git 폴더에서 자동으로 찾고, 없으면 검토된 GitHub 저장소를 자동 설치합니다.

GitHub·Figma 주소는 Base의 검토된 목록에서만 사용하며, 실제 신원은 Git의 v2 Adapter로 다시 검증합니다.

EVIDENCE CEILING

현재 증거 경계

ROUTING_REGISTERED
canonical Figma 경로 등록 상태이며 Figma 업로드 증거가 아닙니다.
ANCHOR_EVIDENCE_MISSING
프로젝트 소유 승인 anchor 증거가 없으면 visual Studio 시작을 차단합니다.
BLOCKED_UNVERIFIED
Windows Studio child · Android · local Bridge 실전달 · provider 생성 품질은 각각 별도 실행 증거가 필요합니다.
INCLUDED_OR_LOCAL_HANDOFF
visual Studio의 import/handoff 경로 자체는 AI 생성 증거가 아닙니다.
HARDENED_RUNTIME_DEFERRED
동일 OS 사용자 계정과 기기 관리자는 신뢰 대상입니다. 도구 실행 중 Base·Studio 파일을 편집하지 마세요.
