# Lettering Production and Review

## 글자 형태가 먼저

1. **의미**: 정확한 문구·언어·세계관에서 핵심 인상을 도출한다. 기존 승인 로고의 보존/교체 범위와 실제 consumer를 확인한다.
2. **비교**: 프로젝트 reference와 원출처에서 형태·무게·자간·리듬·장식 원리를 비교한다. 외부 게임 로고의 식별 가능한 조합을 그대로 제품 로고로 채택하지 않는다.
3. **베이스**: 적법한 폰트 기반 변형인지 독자 레터링 후보인지 구분한다. 특정 폰트를 모든 프로젝트의 정답으로 쓰지 않는다.
4. **형태**: 효과 없는 단색 형태로 획, 내부 공간, 가로세로 비례와 무게 중심을 잡는다. 대표 글자의 특징을 다른 글자에 적용하되 한글 자모·받침 구별을 보존한다.
5. **시각 보정**: 개별 글자쌍과 전체 자간을 구분한다. 수치가 같아도 균형은 다를 수 있으므로 실제 크기에서 무게·여백·획 뭉침을 확인한다. 가로/세로/대각선 획 비율은 관찰 후 조정하며 고정 배수를 강제하지 않는다.
6. **장식**: 실루엣과 가독성이 성립한 뒤 컨셉에 필요한 모티프·질감·빛만 더한다. 장식 없는 판과 비교하고 글자를 가리면 줄인다.
7. **출력**: 메뉴/배너 등 실제 사용처별 크기·배경·크롭으로 확인한다. 작은 표현이 실패하면 효과를 줄인 파생안을 만들되 새 브랜드 형태로 몰래 바꾸지 않는다.

## 도구·원본

실제 연결된 이미지 생성/편집 도구와 기존 프로젝트 제작 경로를 사용한다. 상업 편집기나 새 MCP를 필수 전제로 만들지 않는다. 벡터/레이어/폰트 편집 기능은 존재와 실행 readback을 확인한 경우에만 사용했다고 기록한다.

- 이미지 모델 출력은 후보다. 정확한 문자열과 편집 가능한 최종 graphics layer를 확인하며 이미지 속 한글을 그대로 확정하지 않는다.
- source, 장식/효과, 배포 출력의 역할을 구분한다. 이름만 PSD/SVG/ASE인 파일이나 PNG를 넣은 컨테이너는 편집 가능한 글자 원본 증거가 아니다.
- 기존 프로젝트 경로·asset catalog를 재사용한다. 검수에 필요한 preview는 증거로 보존하고 불필요한 임시 export만 소유권·참조·복구를 확인해 정리한다.
- 실제 제작 도구가 부족하면 brief/생성 후보/편집 원본 중 가능한 단계와 `BLOCKED_UNVERIFIED`를 분리한다. 수동 제작용 SVG·도형으로 이미지 생성 요구를 몰래 대체하지 않는다.

## 폰트·참조 권리

폰트 이름만이 아니라 실제 배포처·파일/버전·license를 확인한다. 이미지에서 폰트를 단정하지 않는다.

- OFL 폰트를 이용한 로고/그래픽과 폰트 소프트웨어 자체의 수정·묶음 배포는 별개다. 공식 OFL FAQ §1.1–1.1.2는 로고 제작을 허용하고 결과물에 OFL을 강제하지 않는다고 설명한다.
- 폰트 파일을 게임에 포함하거나 수정/재배포하면 license 보존, Reserved Font Name 등 해당 조건을 별도로 확인한다. 모든 무료/상업 폰트에 OFL 조건을 일반화하지 않는다.
- 외부 강의의 라이선스 요약보다 실제 폰트 license/공식 원출처가 우선이다. 상표·참조 유사성·상업 배포 미확인은 기존 `docs/knowledge/game-development/PLATFORM_REVIEW_ASSET_RIGHTS_AND_REFERENCE_PRODUCTION_GUIDE.md`로 연결하고 배포 PASS를 주장하지 않는다.

## 실패를 찾는 검수

| 확인 | 증거 |
|---|---|
| 정확한 문구·언어 | 원문과 글자별 대조; OCR만으로 한글 정확성 확정 금지 |
| 읽힘·형태 | 효과 없는 판과 최종 판, 실제 최소 사용 크기 |
| 배경·투명도 | 밝고 어두운 실제 배경, alpha/가장자리/잘림 검사 |
| 작은 화면과 큰 배너 | 같은 형태의 축소·확대/크롭 readback; 필요한 파생안만 |
| 편집 가능성 | 실제 source 재열기와 글자/효과 분리 확인 |
| 게임 연결 | 승인 자산 경로·consumer와 실제 화면 캡처; 문서 preview로 대체 금지 |

예: 가상의 `밤의 항로`가 256px 메뉴와 큰 배너에 필요하다면, 절제된 해양 미스터리라는 인상에서 획·공간을 비교한다. 물결 장식을 기본값으로 단정하지 않으며, 작은 메뉴에서 읽히지 않는 빛 효과는 줄인다. 이 예시는 실제 프로젝트 정본이나 승인 시안이 아니다.

## 근거와 적용

2026-09-16 확인. 사용자 제공 레터링 강의의 **컨셉 → reference → 무게/형태 → 균형 → 장식**은 ADAPT. 강의의 OFL 제한 일반화와 예시 게임 로고 복제는 REJECT.

- [Open Font License FAQ](https://openfontlicense.org/ofl-faq/): artwork와 font software 조건 구분을 ADOPT. 실제 사용 폰트 license는 별도 확인.
- [Adobe kerning and tracking](https://helpx.adobe.com/illustrator/desktop/design-with-text/edit-format-text/adjust-kerning-and-tracking.html): 글자쌍/전체 간격 구분을 ADAPT. Illustrator 설치를 요구하지 않으며 한글 결과는 실제 시각 검수.
